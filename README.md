# Glowing Insights & 3D Lemon Games

A modern React + TypeScript + Three.js web application rewritten from the original static codebase.

## Overview

- **Glowing Insights**: Portfolio showcase featuring dual animated rainbow and playful typing effects, parallax hero banner with animated GIF backgrounds, interactive portfolio selection, and an animated contact form.
- **Project One — Neon Dreams**: Cyberpunk retro-futurism experience featuring an infinite moving 3D perspective grid, randomized floating neon particle system, slide-out neon drawer menu, and authentic neon glowing typography.
- **Project Two — 3D Lemon Games**: Comprehensive 3D game suite powered by Three.js:
  - **Level 1 (Standard Maze)**: Procedurally generated maze with recursive backtracking algorithm, ceiling, wall sliding collision detection, rotating 3D landmark collectibles, radar minimap, first-person WASD/mouse look controls, and victory celebration beacon.
  - **Level 2 (Parkour in Sky)**: Sky-high platforming with 40 spiral platforms of diverse shapes, double-jump physics, sprint sound synthesizer, radar minimap, and cheat modes (Flying with `R`, Speed boost with `E`/`F`).
  - **Level 3 (Parkour in Lava)**: Magma and lava themed parkour with atmospheric fog, heat glow, and precision jumping challenges.
  - **Level 4 (Minecraft Parkour)**: Minecraft block platforms including grass, obsidian, slime blocks (bouncing), ice, and diamond beacon goal.

## Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, custom neon and cyberpunk shaders/animations
- **3D Graphics**: Three.js
- **Audio**: Web Audio API oscillator synthesis
- **Icons**: Lucide React
